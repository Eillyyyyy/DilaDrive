# DilaDrive Customer Flutter Starter

1. Install Flutter SDK and Android Studio / Android SDK.
2. Open a terminal in this folder.
3. Run `flutter pub get`.
4. Run `flutter run`.

The current app is a navigable UI starter with feature tiles. It does not yet implement live authentication, backend data, photo upload or FCM.
Set the API URL in `lib/config/app_config.dart` for your environment.
