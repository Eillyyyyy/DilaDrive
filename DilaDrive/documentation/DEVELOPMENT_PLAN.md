# DilaDrive Development Plan

## Milestone 1 — UI prototype
- Admin dashboard and module navigation
- Customer mobile starter
- Driver mobile starter
- Demonstrate screens using sample data

## Milestone 2 — Data model
- Confirm final ERD and table relationships
- Apply PostgreSQL schema
- Add JPA entities, repositories and services

## Milestone 3 — Authentication
- Password hashing
- JWT access token and expiry
- Roles: ADMIN, CUSTOMER, DRIVER
- Authorization tests for protected routes

## Milestone 4 — Core workflow
- Booking CRUD and cancellation rules
- Admin verification and driver/vehicle assignment
- Driver trip status lifecycle
- Pickup/drop-off photo upload

## Milestone 5 — Corporate and payment workflow
- Quotation, purchase order, invoice and receipt
- Payment receipt upload and admin verification
- Input validation and audit trail

## Milestone 6 — Notifications and testing
- FCM token registration and push notifications
- API and UI integration
- Test edge cases and permissions
- Prepare deployment, demo script and user manual
